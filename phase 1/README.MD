Overview

Assignment 1.1 explores how composition, lighting, and value can change the emotional impact of a still‑life drawing.

• The original poster focuses on calm balance, soft shading, and realistic form.
• The tweaked poster pushes contrast, tension, and expressive smudging to create a more dramatic mood.
• The reflection audio explains the artistic decisions behind both versions and how small adjustments can transform the viewer’s experience.

Overview

Assignment 1.2 demonstrates digital design principles such as unity, rhythm, emphasis, color harmony, and smooth gradients.

The final illustration uses:

• Repeated organic shapes to create rhythm
• Warm‑to‑cool gradients for atmosphere
• A clear focal point using contrast and lighting
• Layered depth to unify the composition


The reflection audio explains how these choices support the prompt and create a cohesive visual experience.
